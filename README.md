# ClientPortal MVP

Een eerste werkende SaaS-basis voor freelancers:
- klantportaal/dashboard
- klanten
- taken
- facturen
- eenvoudige backend API
- responsive interface
- prijsmodel

Dit is een MVP. Voor productie moeten authenticatie, database, bestandsopslag, e-mail, betalingen, autorisaties, audit logs, backups en beveiliging worden toegevoegd.

Omdat je minderjarig bent kunnen accounts, betaalproviders en bedrijfsregistratie leeftijds- of identiteitsvereisten hebben. Regel dit waar nodig met een ouder/voogd en omzeil geen leeftijdscontroles.
